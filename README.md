# Парсер компаний на Ubuntu

Сервис запускает `interlark/parser-2gis` и собственный парсер Яндекс Карт в Chrome. Ключ `PARSER_API_KEY` используется для связи вашего сайта с этим сервисом. [Репозиторий парсера 2ГИС](https://github.com/interlark/parser-2gis)

## Установка на VPS

Сначала сохраните старый скрипт и сверьте резервную ветку. Для установки потребуется Ubuntu с systemd, свободный порт `8765` на loopback и доступ к GitHub, PyPI и Chrome. Исполняйте команды из каталога распакованного архива под `root`.

```bash
bash install-vps.sh
```

Сервис работает под пользователем `persermaps-github`. Файлы лежат в `/opt/persermaps-github`, ключ и пароль страницы хранятся в `/etc/persermaps-github.env`, а SQLite в `/var/lib/persermaps-github/called.sqlite3`. Для обновления уже установленного приложения запустите `bash install-vps.sh --app-only` из актуального checkout.

## Проверка на VPS

```bash
curl -fsS http://127.0.0.1:8765/health
python3 /opt/persermaps-github/check-api.py 2gis Таганрог Стоматология 2
python3 /opt/persermaps-github/check-api.py yandex Таганрог Стоматология 2
python3 /opt/persermaps-github/check-api.py both Таганрог Стоматология 20
python3 /opt/persermaps-github/check-api.py both все все 10
```

`check-api.py` печатает число карточек с адресом, телефоном и соцсетями. `--show` выводит карточки. Список меток `issues` сообщает о недоступности карты, несовместимой разметке и превышении времени поиска. При поиске `все` сервис перебирает российские города и рубрики из каталога установленного `parser-2gis`. Издатель карты определяет контакты, доступные в каждой карточке.

Для разбора сохранённой карточки Яндекс Карт используйте HTML-файл с открытой вкладкой «Контакты». Команда выведет JSON с названием, адресом, телефонами и соцсетями.

```bash
/opt/persermaps-github/venv/bin/python /opt/persermaps-github/yandex_chrome.py --html ./card.html
```

Если в HTML отсутствует канонический адрес карточки, передайте её ссылку параметром `--card-url`. Для живого поиска Chrome на сервере нужен доступ к выдаче Яндекс Карт.

`PARSER_DEFAULT_SOURCE` в файле `/etc/persermaps-github.env` задаёт источник для запросов с полями `city`, `company`, `limit`. Возможные значения `both`, `2gis`, `yandex`. При отсутствии настройки используется `both`. Перезапустите службу после изменения. Команда `check-api.py default Таганрог Стоматология 20 --show` проверяет запрос без поля `source` и выводит карточки в виде текста.

## Страница парсера

Веб-страница открывается на `/`. Она отправляет запросы в API на том же адресе и даёт выбрать 2ГИС или Яндекс Карты. Логин `parser`, пароль берётся из `PARSER_WEB_PASSWORD`. Используйте HTTPS при публичном доступе к странице.

В таблице виден только адрес домена соцсети. По нажатию открывается страница компании по исходной ссылке.

Направьте `parser.example.com` на IPv4 VPS. Запустите команду из checkout под `root`, подставив имя поддомена и IP сервера. Скрипт добавит HTTPS-хост в Caddy и проверит вход на страницу.

```bash
bash publish-web.sh parser.example.com 203.0.113.42
```

Добавьте ссылку в меню основного сайта после проверки HTTPS. Контракт API для серверных интеграций доступен на `/docs`. Инструкция по кнопке находится в [промте для подключения](PROMPT-INTEGRATION.md).
